# 16-bit-Single-Cycle-CPU-Design-Verilog-HDL-
Designed and implemented a 16-bit single-cycle CPU based on the TSC instruction set using  Verilog HDL. Integrated an ALU, register file, control unit, datapath, and program counter to  execute five instructions (ADD, ADI, LHI, JMP, WWD) in a single clock cycle. Successfully passed all  provided functional tests.
